# 抖音主页作品提取工具

Chrome 扩展，版本 **0.3.22**。在抖音账号主页采集作品列表，在热点宝提取达人信息，并支持同步到用户自己的飞书多维表格。

## 下载与安装

1. 下载 [完整源码与安装包](./douyin-creator-extractor-0.3.22.zip?raw=true)，然后解压。
2. 在 Chrome 地址栏输入 `chrome://extensions/`，开启右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择包含 `manifest.json` 的文件夹。
4. 刷新已打开的抖音或热点宝页面。

安装包包含完整可编辑源码、图标和测试，不需要 npm 构建。若使用仓库顶部 **Code → Download ZIP**，解压仓库后，还需解压其中的 `douyin-creator-extractor-0.3.22.zip`，再加载扩展。

## 功能

- 账号主页作品采集：标题、标签、作者、封面、点赞、评论、收藏、分享、时长、发布日期和视频链接。
- 按发布日期、点赞门槛筛选作品，按点赞或评论排序后同步。
- 热点宝达人基础信息、近 30 天作品互动数据及粉丝画像提取；支持 JSON 下载。
- 同步当前单条作品，可选读取前 3 条热评。
- 支持暂停手动采集。
- 可选飞书同步、阿里云语音转写，以及指定会话分享视频的监控入库。

“主页作品采集”指作品信息和链接的采集，不等于批量下载全部视频文件。可采集范围受当前登录状态、主页可见内容及平台接口限制影响，不能保证覆盖隐藏、删除或限制访问的作品。热点宝近 30 天作品数据属于内容互动数据。

## 配置飞书

公开版未预填任何个人表格、授权码或密钥。首次使用同步功能前，点击扩展图标进入设置：

1. 填入自己的 Base 链接，使用“从 URL 填入”或手动填写 `app_token/base_token` 和 `table_id`。
2. 选择多维表格个人授权码模式，填入自己的授权码；也可使用有相应权限的自建应用 `App ID / App Secret`。
3. 点击“测试连接”，再保存设置。
4. 在抖音主页点击“同步主页作品”或“筛选作品同步”。

主页作品写入当前 Base 的“竞品达人视频数据”表；程序可能自动创建该表及所需字段。若链接是 Wiki 链接，需使用底层 Base 的真实标识。

## 可选功能

私聊监控和启动时打开监控页在公开版中**默认关闭**。需要使用时，自行填写会话名称、自己的抖音昵称，再主动开启。仅抓取配置会话中自己分享的视频。

语音转写默认关闭，需要自行配置阿里云百炼 API Key；手动任务也需勾选转写。启用后会向阿里云提交视频媒体地址，可能产生相应服务费用。

## 数据与权限

- 凭据保存在当前 Chrome 扩展的本地存储中，不随本仓库分发。
- 采集依赖当前浏览器登录状态和抖音页面/网络响应；飞书同步会向用户配置的飞书表格发送采集结果。
- `storage` 保存设置和任务；`tabs` 管理采集页；`alarms` 处理后台任务；`debugger` 用于已有的媒体解析和页面数据采集功能；`activeTab` 响应扩展操作。
- 网站权限涵盖抖音/热点宝、飞书 API 及可选的阿里云接口。浏览器可能显示扩展正在调试的提示。
- 发布包不包含浏览器登录状态、Cookie、个人授权码、API Key 或真实采集数据。

## 开发与验证

建议使用 Node.js 22 或更新版本执行已有测试：

```bash
node --test tests/*.test.cjs
```

主要入口：`manifest.json`、`background.js`、`douhot-extractor.user.js`、`douyin-profile-capture.js`、`douyin-profile-cache.js`。本次开源整理清空个人配置并关闭默认私聊监控，原有采集流程保持。
